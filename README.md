# UDIR product site

Static, responsive English-language product website for the Universal Digital Identity Reader concept.

## Preview locally

Open `dist/index.html` in a modern browser. No build step is required.

## Structure

- `dist/index.html` - content and accessible page structure
- `dist/styles.css` - responsive design, animations and use-case illustrations
- `dist/app.js` - mobile navigation, specification tabs, reveal effects and contact-form handling
- `dist/assets/udir-device.png` - supplied UDIR concept render

The contact form does not transmit data to a server. After validation, it prepares an email in the visitor's mail application.
